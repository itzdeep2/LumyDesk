# LumyDesk 🌸
A pastel study website for students, built with HTML, CSS and JavaScript.

## Features
- Pomodoro timer (focus, short break, long break)
- To-do list and notes (saved in the browser)
- Subjects and chapters, drag them into a weekly planner
- Calendar showing what is planned each day
- Progress graphs (subject completion and focus minutes)
- 5 pastel themes plus an auto theme that changes with time of day and timer mode

## How to run
Open `index.html` in your browser (or use VS Code Live Server).
